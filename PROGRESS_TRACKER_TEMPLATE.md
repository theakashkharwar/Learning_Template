# Progress Tracker Template

Use this once per week.

The goal is to measure skill, not motivation.

## How To Use

Use this every Day 7.

Order:

1. Fill the week summary.
2. Fill one daily log for each study day.
3. Score your skills honestly.
4. Pick the weakest high-value skill.
5. Decide next week's main focus.

Do not make the tracker pretty. Make it honest.

## Week Summary

```text
Week number:
Dates:
Total study hours:
Main topics:
Labs solved:
Mini reports written:
Tools practiced:
Biggest improvement:
Biggest weakness:
```

## Daily Log

```text
Day:
Topic:
Hours studied:
Labs solved:

Output created:
Daily score out of 5:
One thing I understood:
One thing still unclear:
```

## Skill Scorecard

Score each from 1 to 5.

```text
HTTP requests/responses:
Cookies and sessions:
JavaScript reading:
Backend logic:
Burp Proxy:
Burp Repeater:
Authentication testing:
Access control testing:
XSS:
SQL injection:
Report writing:
Real target methodology:
```

Meaning:

- 1 = I have heard of it.
- 2 = I understand basic theory.
- 3 = I can solve beginner labs.
- 4 = I can test it without hand-holding.
- 5 = I can find, explain, and report it in realistic situations.

## Weekly Review Questions

```text
What did I actually build or produce this week?
Which vulnerability do I understand better now?
Which tool action became easier?
Where did I waste time?
Did I watch too much and practice too little?
What topic should I repeat next week?
What is my next high-value weakness?
```

## Next Week Plan

```text
Main focus:
Secondary focus:
Labs to solve:
Tool skill:
Reports/writeups to read:
Expected outputs:
```

Minimum weekly outputs:

- 5 solved labs
- 3 mini reports
- 2 checklists
- 1 weekly review

Strong weekly outputs:

- 10+ solved labs
- 5 mini reports
- 1 complete topic checklist
- 1 Burp workflow note
- 1 realistic target testing plan

## Copy-Paste Prompt For Weekly Review

Use this at the end of every week.

```text
You are my offensive web security accountability coach. I am following a 6-month plan to become job-ready in web exploitation and bug bounty.

Here is my weekly log:
[PASTE WEEKLY LOG]

Analyze my week honestly. Tell me:
1. What improved in practical skill.
2. What was passive or low-value.
3. Which weak point is most dangerous for my 6-month goal.
4. Whether I practiced enough with Burp/labs/reports.
5. What I should repeat next week.
6. What I should stop doing.
7. My next week's topic order.
8. A realistic 6-day routine for next week.
9. One measurable target for the week.

Be practical and direct. Do not motivate me with generic advice. Help me improve the system.
```
